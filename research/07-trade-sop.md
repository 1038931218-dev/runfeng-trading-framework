## 0. 执行分工（2026-11-07 更新）
- **Mika = 唯一交易员**：在通达信下单/撤单；DSH/润行只发令、核对、记录，**可只读查看行情/持仓/委托，但不点任何买卖按钮**。
- 指令通道：Mika 固定会话「交易系统备份执行员」；禁止新开对话。
- 指令格式：代码/方向/价格/数量/止损/有效期/理由/guard 结果。
- 回报格式：成交价、数量、费用、成交后可用资金、委托状态（未成交说明原因）。
- 冲突处理：Mika 先复核 plan 与红线，冲突立即回报、不照做。

## 1. 原则（不可跳步）

1. **自主执行（2026-11-07 用户授权）**：用户不干预计划，润行全权决定买什么/何时买卖/多少/止损，**不再逐单请示**；润行负责盯盘、填单、直接提交。
2. **登录态免密（2026-11-07 用户确认）**：用户每天早上在通达信登录一次，**当日下单不再验证交易密码/指纹**。因此润行可在登录态下全程无人下单；**唯一需要用户的是「当天首次登录」**——若 App 要求重新登录/登录失效（读不到资产页），用 `mcp__phone__handoff` 请用户登录一次，登录后继续。不接触、不索取、不保存密码。
3. **留痕**：每单先写一行「代码/方向/价格/数量/预计金额/预计费用」，成交后回填实际结果；不再等待用户回「确认」。
4. **不碰**：银证转账、融资融券、修改密码、销户/换卡、他人委托；不安装任何声称能「自动下单」的第三方客户端。
5. **只做现金账户**：不融资、不加杠杆；卖出资金 T+1 可用（当日可用不可取）。
6. **记录留痕**：每笔成交后，把「时间/代码/方向/成交价/数量/费用/成交后现金与持仓」写回 `reports/` 当日文件或账户日志，供次日复盘。

## 3. 下单流程（以周一为例）

### 3.1 买入（首笔仅 1 手，限价）
1. 09:25 前：确认「可用资金」≥ 标的金额 + 约 5 元费用；核对标的在名单内（中国建筑/大秦铁路/国电电力）。
2. 交易 → 买入 → 输入代码（如 `601668`）→ 输入限价（≤4.66，**不追价**）→ 数量 `100` → 核对「预计金额/可用余额」。
3. 先跑 `python3 tools/daily_ops.py guard <代码> buy <价> <量>`（PASS 才下单）→ 直接提交（登录态免密）→ 查看「当日委托」状态。
4. 成交后截图/抄录：成交价、数量、佣金、成交后可用。

### 3.2 卖出（万科 400 股，仅在触发时）
1. 触发条件：**示例止损价云条件单提醒**（用户手机弹提醒）→ 用户告知我 → 我填单确认；或用户自行按提醒卖出。
2. 交易 → 卖出 → 代码 `000002` → 价格：限价挂「买一价」或对手价（急跌用市价/对手价，避免挂单不成）→ 数量 `400` → 核对「可卖 400」。
3. 先跑 guard 校验 → 直接提交（免密）→ 查当日成交；成交后 `python3 tools/daily_ops.py ack`。

### 3.3 撤销/改单
- 未成交：交易 → 撤单 → 找到委托 → 撤单（需确认）。
- 云条件单到期（11-12）：交易 → 云条件单 → 我的条件单 → 续期/重设（3.16 或按用户最新决定）。

## 4. 盘中纪律（与团队日报一致）

- **09:30–10:00 不新开仓**（CPI/PPI 数据窗口），只处理止损类卖出。
- **下单前检查清单**：① **板块权限：只做沪深主板（600/601/603/605、000/001/002/003）；科创板 688/689、创业板 300/301、北交所 8/4/920 一律不可买**（用 `python3 tools/account_filter.py <代码>` 校验）；② 单票 ≤20% 且首笔 ≤1 手；③ 非 ST/*ST、PE>0；④ 成交额 >2 亿；⑤ mom20 < +18.3%；⑥ 不同时持有 >2 只；⑦ 本周交易 ≤3 笔；⑧ 现金足够且留 ≥60% 现金。
- **指数条件**：上证未收复 MA20 3693.30 → 只允许阶段一 1 手/票；收复且量能确认后 → 才允许 2 手/票。
- **跳空应对**：上证开盘 <3576（逼近 250 日低 3574.27）→ 当天不建仓，只处理止损。
- **涨跌停/停牌**：跌停 2.92（万科）挂单排队可能不成交；停牌不挂单；集合竞价 09:20–09:25 不可撤单，挂单前想清楚。
- **不追高**：现价高于触发价 → 不买，等回踩。

## 5. 费用与对账

- 口径：佣金万 3、**最低 5 元/笔**；印花税卖出 0.05%；过户费双向 0.001%（用户实际佣金率待查，见 `research/05` §6.2）。
- 1 手 471 元往返 ≈ 10.24 元 ≈ 2.17%；**不反复进出**。
- 成交后必须核对：成交价 × 数量 + 费用 ≈ 资金变动；与 App「资金流水」逐笔对账，差异当日提出。

## 6. 异常与升级

| 情况 | 处理 |
|---|---|
| 委托失败/废单 | 看「当日委托」失败原因；资金不足/价格越界/停牌/涨跌停限制，按原因修正后重报 |
| App 断连（20000） | 按 §2 四步恢复；仍不行则用户手动，我口述 |
| 误操作（下错方向/数量） | 立刻撤单；已成交则立即反向？**不反向**（成本+2.17%），记录并当日复盘，等用户决定 |
| 密码/指纹失败 | 用户本人重试；连续失败不强行，改日 |
| 网络/手机异常 | 中止交易，保住现金，不追单 |

本 SOP 只覆盖「在用户授权下、由用户本人完成密码确认」的现金买卖操作；不构成投资建议、不承诺收益；任何滑点、跳空、系统故障造成的损失由用户承担。**用户可随时叫停**。

## 9. 紧急止损授权（2026-11-07 用户确认）

用户可能不在手机/电脑旁，因此授权润行**不经确认直接止损**，三档：

| 档 | 触发 | 动作 |
|---|---|---|
| L0 常规止损 | 计划内止损价（万科 3.16/3.10 等） | 直接卖出，不请示，事后通知 |
| L1 极端行情 | 上证日内跌幅 ≤-3%；或任一持仓日内跌幅 ≤-7% | 直接紧急止损/清仓，不请示，成交后立即通知用户 |
| L2 离线兜底 | 手机不在线/App 掉登录/进程被杀 | 通达信「云条件单·**自动委托**」服务器端触发（不依赖手机）；万科 3.16 单建议尽快从「人工委托」升级为「自动委托」 |

执行约束：仍受红线（单票/行业/止损总额/板块权限）约束；成交后 15:05 复盘必须写清「触发原因、成交价、滑点、与计划差异」。
**卖出的钱不用于当日再买入**（避免恐慌中加仓）。
